# Omar Khayyam — sitio web

Landing page mobile-first para **Omar Khayyam**, bar y restaurante en Calle de la Amargura, San Pedro (San José, Costa Rica).

## Stack

- HTML / CSS / JS estático
- Hosting: Cloudflare Pages
- Desarrollado por [Exha Tech](https://exhatech.com)

## Desarrollo local

Abra `index.html` en el navegador, o sirva la carpeta:

```bash
npx serve .
```

## Deploy

```bash
npx wrangler pages deploy . --project-name=omar-khayyam --commit-dirty=true
```
